# SEBI.dev

직접 써보고, 흐름이 끊기는 지점을 찾아 다듬는 프론트엔드 개발자 이세비의 포트폴리오입니다.

## Stack
Next.js (App Router) · TypeScript · Tailwind CSS v4 · Motion · next-themes · Vitest · Playwright · Vercel

## Scripts
| | |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm test` | 단위 테스트 (Vitest) |
| `npm run e2e` | E2E 테스트 (Playwright) |
